# 🏠 家用路由器 IPv6 远程访问“满血版”部署笔记

本笔记记录了如何通过 **IPv6 + Cloudflare + ddns-go + Lucky** 构建一个稳定、全自动且具备合法 SSL 绿锁证书的远程管理方案。

---

## 🚀 核心架构
*   **DNS 解析**：Cloudflare (AAAA 记录)
*   **动态同步**：ddns-go (实时同步动态 IPv6)
*   **证书管理**：Lucky ACME (基于 DNS 验证自动申请/续期证书)
*   **安全转发**：Lucky 反向代理 (加持 TLS 绿锁并转发流量)

---

## 1️⃣ Cloudflare 基础设置
1.  **添加记录**：在 DNS 页面手动添加一条 `AAAA` 记录。
2.  **主机名**：`@` (对应域名 `ax6000.xxx.cc`)。
3.  **代理状态**：**必须关闭代理 (灰色云朵)**。
    *   *注：开启代理（橙色云朵）仅支持标准端口，且会隐藏真实 IP，不利于非标端口直连。*
4.  **API Token**：创建一个具有 `Zone:DNS:Edit` 权限的令牌，供插件使用。

## 2️⃣ ddns-go 配置 (解决 IP 变动)
1.  **DNS 服务商**：选择 Cloudflare，填入 API Token。
2.  **IPv6 设置**：
    *   勾选 **启用**。
    *   获取方式：选择“通过网卡获取”（通常为 `ppp0`）。 如果是光猫拨号、路由器接光猫的模式，网卡建议选 br0，因为它通常对应路由器在内网环境中的全球单播地址，且与管理服务绑定更紧密
    *   Domains：填入 `ax6000.xxx.cc`。
3.  **IPv4 设置**：直接 **取消勾选** (避免因无公网 IPv4 导致插件报错)。

## 3️⃣ Lucky SSL 证书申请 (全自动绿锁)
1.  **证书管理**：点击“添加证书”，方式选择 **ACME**。
2.  **验证方式**：选择 **DNS 验证 (Cloudflare)**，填入 Token。
3.  **域名**：`ax6000.xxx.cc`。
4.  **自动化**：Lucky 会自动通过 DNS 验证获取证书，并在到期前自动续期。
    *   *优势：一旦开启 TLS，Lucky 会自动读取内部生成的证书路径，无需手动下载或上传到路由器系统。*

## 4️⃣ Lucky 反向代理配置 (核心转发)
为了避免端口冲突，采用“门卫模式”：

### 第一步：腾出端口
*   进入 **华硕后台 -> 系统管理 -> 系统设置**。
*   将路由器原有的远程管理端口（如 `2525`）修改为一个新数字（如 **`12525`**）。
*   *目的是将 `2525` 这个“门面端口”留给 Lucky 使用。*

### 第二步：Lucky 主规则 (守大门)
*   **监听端口**：`2525` (外网访问端口)。
*   **TLS 模式**：**开启 (ON)**。

### 第三步：Lucky 子规则 (内部分发)
*   **前端地址**：`ax6000.xxx.cc:2525`。
*   **后端地址**：`https://127.0.0.1:12525` (指向路由器后台真实的 HTTPS 端口)。
*   **忽略后端 TLS 验证**：**是** (解决华硕自带自签名证书导致的 502 错误)。
*   **使用目标地址 Host 请求头**：**是** (解决部分固件的主机头安全校验)。

## 5️⃣ 服务扩展 (如 8181 端口)
如果需要远程访问其他固定端口的服务（如 8181）：
1.  **Lucky 新建主规则**：监听新端口（如 `8182`），开启 TLS 并关联同一张证书。
2.  **子规则**：前端 `ax6000.xxx.cc:8182` -> 后端 `http://127.0.0.1:8181`。
3.  **访问**：`https://ax6000.xxx.cc:8182`。

---

## ⚠️ 避坑指南
*   **协议头匹配**：访问时必须带上 `https://`。如果不加 `s` 访问加密端口，连接会被重置。
*   **回流限制**：在内网 Wi-Fi 下域名可能无法访问（NAT Loopback 限制），请使用 **手机 5G 信号** 进行最终稳定性测试。
*   **IPv6 环境**：访问端（手机、公司电脑等）必须具备 IPv6 访问能力。
*   **安全加固**：暴露公网后，务必确保管理员账号密码具有极高强度，防止暴力破解。

如果 `ddns-go` 已经在正常工作，说明 Token 就存在它的配置文件里：
*   **配置文件路径**：`/koolshare/configs/ddnsgo/default.yaml`
